icon: House
---

PurrOS covers people, scheduling, time, cash, inventory, ordering, sales, checklists, equipment, communication and reporting across one location or many.

<Callout title="Early development" type="warn">
PurrOS has no tagged release yet. The **API server and `purros` CLI work today** and cover every feature area; the **web app is not built yet**. Throughout these docs, anything marked <Planned /> isn't built, screens ("**Settings → …**") arrive with the web app, and each feature guide starts with what works today and ends with the endpoints you can use now. See the [roadmap](https://github.com/selectdev/PurrOS/blob/main/PRODUCT.md#9-roadmap).
</Callout>
