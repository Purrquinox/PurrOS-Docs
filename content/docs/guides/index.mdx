Each guide starts with the feature's switch, what it depends on, and **what works today**, and ends with the API endpoints and webhook events you can use now. Until the web app ships, everything described as a screen is available through the [API](/docs/api).

## How the features fit together

Features build on each other: sales feeds drive cash, inventory usage and forecasting; punches become timesheets and payroll hours; everything rolls up into reports. Arrows show what a feature **needs** to be switched on.

<Mermaid
  chart={`flowchart LR
  people["People & HR"] --> time["Time & Attendance"]
  time --> scheduling["Scheduling & Forecasting"]
  people --> scheduling
  people --> ea["Employee Area"]
  sales["Sales"] --> cash["Cash Management"]
  inventory["Inventory"] --> purchasing["Purchasing & Ordering"]
  sales -.->|usage recipes| inventory
  sales -.->|demand| scheduling`}
/>

Solid arrows are hard dependencies. Dotted arrows are optional: usage recipes need Sales, and forecasting uses sales data when Sales is on. See [Feature switches](/docs/platform/administration/feature-switches).
